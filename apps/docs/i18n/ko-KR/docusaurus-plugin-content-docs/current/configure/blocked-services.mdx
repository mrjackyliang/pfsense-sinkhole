별도 목록 URL을 선택하고 유지하지 않고 브랜드 전체를 차단하려면 **Firewall → Sinkhole → Services**를 사용합니다.

## 범위 선택 \{#choose-a-scope}

**Global**, 구성된 네트워크 또는 구성된 장치를 선택합니다. 서비스를 검색하고 그룹 칩으로 타일 범위를 좁힌 다음 각 서비스의 확인란을 선택하고 서비스 타일 아래의 **Save**를 선택합니다.

선택 항목은 해당 범위의 기존 수준에서 컴파일됩니다. 장치 허용 도메인은 장치 서비스 규칙보다, 네트워크 허용 도메인은 네트워크 서비스 규칙보다, 전역 허용 도메인은 전역 서비스 규칙보다 계속 우선합니다.

전용 Bypass 보호가 담당하는 서비스는 그리드, 그룹 수 또는 검색에 표시되지 않습니다. Private Relay는 Bypass 탭에서만 구성합니다.

## 레지스트리 및 복구 \{#registry-and-repair}

Sinkhole은 이 페이지가 열리거나 **Refresh**를 선택할 때만 AdGuard Home 서비스 레지스트리를 가져옵니다. 마지막 정상 사본을 `/var/db`에 하루 동안 보관하므로 컴파일이 네트워크를 기다리지 않습니다.

서비스 로고는 격리된 data URI 이미지로 렌더링됩니다. 로고가 없거나 너무 크면 일반 이미지를 사용합니다. 저장된 서비스가 새 레지스트리에서 사라지면 Sinkhole은 해당 ID를 유지하고 **Needs Repair** 아래에 표시합니다. 확인란을 지우고 저장하면 그 선택이 제거됩니다.

**Status** 탭에는 레지스트리를 가져온 시간, 마지막 오류 및 구성된 각 범위에서 선택한 차단 서비스 수가 표시됩니다.
