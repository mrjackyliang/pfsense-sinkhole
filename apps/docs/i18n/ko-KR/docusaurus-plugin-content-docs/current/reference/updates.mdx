Sinkhole은 GitHub 릴리스를 확인하고 pfSense를 통해 알림을 보내며 About 탭에서 검증된 새 패키지를 설치할 수 있습니다.

## 예약된 릴리스 확인 \{#scheduled-release-checks}

**General → Update Checks**에서 Daily, Weekly, Monthly 또는 Never를 선택하며 기본값은 Weekly입니다. Sinkhole은 안정적으로 임의 지정된 일정 요소를 저장하므로 설정을 저장할 때마다 확인 시간이 계속 바뀌지 않습니다.

확인 작업은 최신 버전, 릴리스 페이지, 확인 시간 및 마지막 오류를 기록합니다. **About → Check Now**는 동일한 확인을 즉시 실행합니다.

## 업데이트 알림 \{#update-notices}

새로 감지된 각 버전은 Sinkhole의 About 탭으로 연결되는 로컬 pfSense WebGUI 알림 하나를 만듭니다. 같은 버전을 반복해서 확인해도 중복 알림을 만들지 않습니다.

**Remote Notifications**를 선택하면 **System → Advanced → Notifications**에 구성된 서비스도 사용합니다. 이 설정은 기본적으로 꺼져 있으며 목록 차단 알림 규칙이 아니라 버전 알림에 영향을 줍니다.

## About 업데이트 표시줄 \{#about-update-bar}

업데이트 표시줄에는 설치된 버전, 마지막으로 확인한 최신 버전, 마지막 확인, 릴리스 링크, 오류 및 분리된 업데이트 진행 상황이 표시됩니다. 시각적 상태로 대기 중 업데이트 없음, 새 릴리스, 실행 중인 업데이트, 성공 및 실패를 구분합니다.

기록된 최신 버전이 더 새 버전이면 **Update**가 표시됩니다. 페이지는 브라우저 요청을 열어 둔 채 기다리지 않고 분리된 작업을 폴링하여 결과를 보고합니다.

## 설치 전 검증 \{#verification-before-installation}

자체 업데이트는 이 프로젝트의 GitHub 릴리스 다운로드 경로에 있는 자산만 허용하며 다운로드 크기와 시간 제한을 적용합니다. 안정 패키지와 `.sha256` 파일이 모두 필요하며 SHA-256 다이제스트를 검증한 다음 `pkg add -f`로 설치하기 전에 패키지 메타데이터를 검사합니다.

`/usr/local/share/pfSense-pkg-Sinkhole/release-signing.pub`에 신뢰하는 Ed25519 OpenSSH 키가 포함되면 일치하는 분리 `.sig` 자산이 필수가 됩니다. Sinkhole은 `pkg`가 패키지를 검사하기 전에 릴리스 네임스페이스에서 서명을 검증합니다.

설치된 신뢰 목록이 비어 있으면 서명이 필요하지 않지만 체크섬과 패키지 메타데이터 검증은 계속 적용됩니다. 자산이 없거나 잘못되었거나 신뢰할 수 없거나 너무 크거나 일치하지 않으면 업데이트를 중단하고 설치된 패키지를 그대로 둡니다.

## 업데이트 잠금 \{#update-locking}

패키지 확인과 자체 업데이트는 DNS 목록 및 IP/국가 업데이트와 `/var/run/sinkhole-update.lock`을 공유합니다. 목록 업데이트가 진행 중이면 해당 작업이 끝날 때까지 About의 **Update** 작업을 시작할 수 없습니다.

잠금은 현재 패키지가 정책을 다운로드, 구문 분석, 컴파일 또는 적용하는 동안 패키지 파일이 변경되지 않도록 합니다. Status에 업데이트 실행이 더 이상 표시되지 않으면 About에서 다시 시도합니다.

## 수동 패키지 업데이트 \{#manual-package-update}

About 작업을 사용할 수 없을 때도 안정 명령을 사용할 수 있습니다.

```sh
pkg add -f https://github.com/mrjackyliang/pfsense-sinkhole/releases/latest/download/pfSense-pkg-Sinkhole.pkg
```

실행하기 전에 안정 `.sha256` 자산을 다운로드하고 [설치](/docs/installation#verify-the-checksum)에 설명된 대로 해시를 패키지와 비교합니다. 같은 안정 URL에서 가져온 경우에도 `-f`가 있어야 `pkg`에서 새 빌드를 설치할 수 있습니다.

About 권한은 읽기 전용입니다. **Check Now**와 **Update**는 로그인한 사용자에게 Sinkhole General 설정 권한 또는 pfSense의 `page-all` 권한이 있을 때만 표시되고 요청이 허용됩니다. About 권한만 있는 사용자는 설치된 버전, 릴리스 상태 및 릴리스 링크를 계속 확인할 수 있습니다.
