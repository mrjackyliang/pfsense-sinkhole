如果您想阻止整个品牌，而不选择和维护单独的列表 URL，请使用 **Firewall → Sinkhole → Services**。

## 选择作用域 \{#choose-a-scope}

选择 **Global**、一个已配置的网络或一个已配置的设备。搜索服务，使用组芯片缩小磁贴范围，打开或关闭服务，然后选择服务卡片下方的 **Save**。

选择会在该作用域的现有层级编译。设备允许域名仍优先于设备服务规则，网络允许域名仍优先于网络服务规则，全局允许域名仍优先于全局服务规则。

由专用 Bypass 防护涵盖的服务不会出现在网格、组计数或搜索中。Private Relay 只能在 Bypass 标签页配置。

## 注册表和修复 \{#registry-and-repair}

Sinkhole 仅在此页面打开或您选择 **Refresh** 时获取 AdGuard Home 服务注册表。它会在 `/var/db` 下保留最后一份有效副本一天，因此编译永远不会等待网络。

服务徽标会呈现为隔离的 data-URI 图像。缺失或过大的徽标会使用通用图像。如果已保存的服务从较新的注册表中消失，Sinkhole 会保留其 ID 并将其显示在 **Needs Repair** 下；将其关闭并保存即可删除该选择。

**Status** 选项卡显示注册表的获取时间、最后错误，以及为每个已配置作用域选择的已阻止服务数量。
