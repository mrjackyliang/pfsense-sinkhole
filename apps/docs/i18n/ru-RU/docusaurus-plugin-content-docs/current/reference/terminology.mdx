Эти термины имеют одинаковое значение во всех разделах Sinkhole WebGUI и документации.

## DNS Sinkhole \{#dns-sinkhole}

Ответ на заблокированное имя адресом, который никуда не ведёт, чтобы остановить запрос.

## DNS Resolver \{#dns-resolver}

Служба DNS pfSense на основе Unbound.

## Список блокировки \{#block-list}

Добавленный по URL или из поиска список имён или адресов, которые требуется блокировать.

## Сохранённый список \{#saved-list}

Последняя исправная копия списка блокировки, хранящаяся на межсетевом экране.

## Область действия \{#scope}

Место применения списка блокировки: вся сеть, VLAN или одно устройство.

## Глобальные списки \{#global-lists}

Списки блокировки, применяемые ко всем клиентам сети.

## Правило оповещения \{#alert-rule}

Список и область действия, блокировки которых отправляют уведомление pfSense.

## Защита от обхода \{#bypass-protection}

Необязательные средства для отдельных интерфейсов, которые удерживают клиентов на проверяемых Sinkhole путях DNS, перенаправляя обычный DNS или блокируя распространённые альтернативы шифрованного DNS и туннелей.

## Перенаправление обычного DNS \{#plain-dns-redirect}

Необязательная настройка Bypass, которая направляет обычные запросы устройств по TCP и UDP на порте 53 на межсетевой экран.

## Поиск популярных списков \{#popular-list-search}

Поиск широко используемых списков блокировки в WebGUI, подобный средству выбора AdGuard Home.
