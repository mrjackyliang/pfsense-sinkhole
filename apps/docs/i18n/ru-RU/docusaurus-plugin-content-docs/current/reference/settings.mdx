Узнайте назначение и поведение по умолчанию каждой области конфигурации Sinkhole в **Firewall → Sinkhole**.

## General \{#general}

| Поле             | По умолчанию | Описание                                                                                        |
|------------------|--------------|-------------------------------------------------------------------------------------------------|
| Enable           | Off          | Включает запланированные обновления списков и интеграцию Sinkhole с DNS Resolver.               |
| Update Frequency | Daily        | Выбирает расписание Hourly, Every 6 hours, Daily или Weekly для списков DNS, Bypass и IP/стран. |
| Keep Settings    | On           | Сохраняет конфигурацию и постоянные данные при удалении пакета.                                 |

Расписание использует стабильные случайные компоненты. Hourly запускается в одну стабильную минуту, Every 6 hours использует ту же минуту каждый шестой час, Daily запускается в `00:<minute>`, а Weekly — в воскресенье в `00:<minute>`.

## Package Updates \{#package-updates}

| Поле                 | По умолчанию | Описание                                                                                         |
|----------------------|--------------|--------------------------------------------------------------------------------------------------|
| Update Checks        | Weekly       | Выбирает проверку новых выпусков GitHub: Daily, Weekly, Monthly или Never.                       |
| Remote Notifications | Off          | Также отправляет уведомление о каждой новой версии через настроенные в pfSense удалённые службы. |

Каждая новая версия создаёт одно локальное уведомление pfSense. **About → Check Now** сразу выполняет ту же ограниченную проверку выпуска, не меняя расписание.

## Lists \{#lists}

| Поле            | По умолчанию | Описание                                                                                           |
|-----------------|--------------|----------------------------------------------------------------------------------------------------|
| Name            | Empty        | Локальная метка для назначений, оповещений и Status.                                               |
| URL             | Empty        | Источник HTTP или HTTPS без встроенных учётных данных.                                             |
| Enabled         | On           | Включает назначенный источник в обновления и скомпилированную политику.                            |
| Global          | On           | Применяет список ко всем клиентам после решений устройств и сетей.                                 |
| Allowed Domains | Empty        | Один глобальный разрешённый домен в строке; каждая запись разрешает сам домен и все его поддомены. |

**Add from Catalog** выполняет поиск по запросу в реестре списков AdGuard Home и каталоге источников pfBlockerNG. Добавление результата создаёт такую же обычную строку, как ручной ввод URL.

Источники обхода исключены из этого каталога.

## Сервисы \{#services}

По умолчанию выбор сервисов пуст для каждой области. Сервис реестра, охваченный отдельной защитой Bypass, скрывается из Сервисов и удаляется из сохранённого выбора; Private Relay настраивается только на вкладке Bypass.

## Network Scopes \{#network-scopes}

| Поле            | По умолчанию | Описание                                                                                                                     |
|-----------------|--------------|------------------------------------------------------------------------------------------------------------------------------|
| Interface       | Empty        | Настроенный интерфейс pfSense, текущие подсети IPv4 и IPv6 которого определяют сеть.                                         |
| Lists           | Empty        | Дополнительные списки DNS, блокирующие клиентов в сети.                                                                      |
| Allowed Domains | Empty        | Одно сетевое исключение в строке; каждое разрешает сам домен и все его поддомены до списков сети и всей глобальной политики. |
| Enabled         | On           | Включает строку в сопоставление клиентов и скомпилированную политику.                                                        |

Каждый интерфейс может встречаться только один раз. Недоступный сохранённый интерфейс остаётся видимым для исправления, а не удаляется.

## Device Scopes \{#device-scopes}

| Поле                | По умолчанию | Описание                                                                                                                       |
|---------------------|--------------|--------------------------------------------------------------------------------------------------------------------------------|
| Name                | Empty        | Локальная метка, отображаемая в политике и Status.                                                                             |
| Identified By       | IP address   | Выбирает IP address, DHCP static mapping или MAC address.                                                                      |
| IP or MAC Address   | Empty        | Точный идентификатор при выборе IP address или MAC address.                                                                    |
| DHCP Static Mapping | Empty        | Существующее сопоставление, выбранное для этого метода идентификации.                                                          |
| Lists               | Empty        | Дополнительные списки DNS, блокирующие это устройство.                                                                         |
| Allowed Domains     | Empty        | Одно исключение устройства в строке; каждое разрешает сам домен и все его поддомены до каждого сетевого и глобального решения. |
| Enabled             | On           | Включает строку в сопоставление клиентов и скомпилированную политику.                                                          |

Статические сопоставления используют настроенный адрес и текущие адреса, обнаруженные для MAC сопоставления. Строка MAC использует текущие данные ARP, NDP и аренды DHCP.

## Alert Rules \{#alert-rules}

| Поле                 | По умолчанию | Описание                                                                                          |
|----------------------|--------------|---------------------------------------------------------------------------------------------------|
| Description          | Empty        | Локальная метка правила.                                                                          |
| Lists                | Any          | Соответствует любому списку или только выбранным настроенным спискам.                             |
| Clients              | Everyone     | Соответствует всем или выбранным сетевым и устройственным областям действия.                      |
| Repeat After         | 60           | Число минут до повторного уведомления для тех же правила, клиента, домена и списка; от 1 до 1440. |
| WebGUI Notice        | On           | Добавляет уведомление pfSense при совпадении правила.                                             |
| Remote Notifications | On           | Использует настроенные службы уведомлений pfSense при совпадении правила.                         |
| Enabled              | On           | Включает правило в скомпилированную политику оповещений.                                          |

Минутный обработчик отправляет не более 20 сообщений за запуск и 60 сообщений на правило в час, затем обобщает превышение. Он хранит не более 50 непрочитанных уведомлений Sinkhole WebGUI и использует 40-секундный бюджет запуска; события старше 10 минут считаются устаревшими.

## Защита Bypass \{#bypass-protection}

| Поле                | По умолчанию | Описание                                                                                                 |
|---------------------|--------------|----------------------------------------------------------------------------------------------------------|
| Apply to            | Empty        | Интерфейсы входящего клиентского трафика, общие для всех механизмов защиты Bypass.                       |
| Redirect            | Off          | Направляет обычный трафик DNS по портам UDP и TCP 53 на выбранных интерфейсах на межсетевой экран.       |
| Exempt Sources      | Empty        | Один IP-адрес, CIDR, псевдоним или `This Firewall` в строке, обходящий перенаправление обычного DNS.     |
| Exempt Destinations | Empty        | Один IP-адрес назначения, CIDR или псевдоним в строке, обходящий перенаправление обычного DNS.           |
| TLS and QUIC        | Off          | Блокирует порт 853 TCP и UDP к адресатам, отличным от межсетевого экрана.                                |
| Providers           | Off          | Блокирует имена и адреса из включённых Bypass Lists типа **Encrypted DNS**.                              |
| Firefox             | Off          | Возвращает `NXDOMAIN` для контрольного имени автоматического DNS-over-HTTPS Firefox и его поддоменов.    |
| Private Relay       | Off          | Возвращает `NXDOMAIN` для двух имён доступности Private Relay компании Apple.                            |
| Discovery           | Off          | Не изменяет DDR, объявляет DNS over TLS межсетевого экрана или отвечает `NOERROR` без записей.           |
| Tor                 | Off          | Блокирует имена и адреса из включённых Bypass Lists типа **Tor**.                                        |
| VPN providers       | Off          | Блокирует имена и адреса из включённых Bypass Lists типа **VPN**.                                        |
| Standard VPN ports  | Off          | Блокирует UDP-порты OpenVPN, WireGuard и IPsec, а также ESP к адресатам, отличным от межсетевого экрана. |

Все сохранённые исключения перенаправления должны быть допустимы до применения правил перенаправления. IPv4 использует `127.0.0.1`, только когда Resolver слушает на нём, а иначе — адрес интерфейса; IPv6 всегда использует адрес интерфейса. **Discovery → Advertise** требует службу SSL/TLS DNS Resolver и имя узла сертификата.

### Bypass Lists \{#bypass-lists}

| Поле    | По умолчанию  | Описание                                                                             |
|---------|---------------|--------------------------------------------------------------------------------------|
| Name    | Empty         | Локальная метка, отображаемая в Bypass и Status.                                     |
| Kind    | Encrypted DNS | Выбирает политику **Encrypted DNS**, **Tor** или **VPN**.                            |
| URL     | Empty         | Источник HTTP или HTTPS, содержащий вперемешку домены, адреса и CIDR.                |
| Enabled | Off           | Включает сохранённый список в плановые загрузки и соответствующую включённую защиту. |

Ввод Bypass List использует одну запись в строке и комментарии `#`. При сбое загрузки сохраняется последняя исправная сохранённая копия. Решения о разрешении доменов списков имеют приоритет над именами из Bypass Lists, но не над сигналами Firefox, Private Relay или Discovery.

**Add from Catalog** выполняет поиск источников обхода в реестре AdGuard Home и разделах DNS, IPv4 и IPv6 pfBlockerNG только при открытии или обновлении. Каждый результат имеет фиксированный тип **Encrypted DNS**, **Tor** или **VPN** и добавляется как включённый Bypass List.

## IP and Country Blocking \{#ip-and-country-blocking}

| Поле                | По умолчанию | Описание                                                                                |
|---------------------|--------------|-----------------------------------------------------------------------------------------|
| Enable              | Off          | Включает независимо загружаемый якорь межсетевого экрана `sinkhole/ip`.                 |
| Interfaces          | Empty        | Входные интерфейсы, на которых применяются правила блокировки.                          |
| Directions          | Empty        | Выбирает входную блокировку источника, выходную блокировку назначения или оба варианта. |
| Countries           | Empty        | Один двухбуквенный код страны GeoLite2 в строке.                                        |
| MaxMind Account ID  | Empty        | Учётная запись для получения архива GeoLite2 Country.                                   |
| MaxMind License Key | Unset        | Ключ только для записи от администратора; пустое поле сохраняет записанное значение.    |
| Clear License Key   | Off          | Удаляет сохранённый ключ MaxMind при сохранении.                                        |
| IP Allowlist        | Empty        | Один IP-адрес или CIDR в строке, вычитаемый из итоговых таблиц блокировки.              |

В каждой строке списка IP есть имя, URL, выбор семейства IPv4/IPv6/Both и переключатель Enabled. Sinkhole также удаляет из итоговых таблиц адреса интерфейсов межсетевого экрана, шлюзов и DNS, чтобы его правила не блокировали защищённую инфраструктуру.

IP-каталог исключает все источники Encrypted DNS, Tor и VPN, принадлежащие каталогу Bypass.

## Язык \{#language}

WebGUI Sinkhole использует языковую настройку pfSense; полные каталоги доступны для всех 18 поддерживаемых языков и региональных вариантов. Если ключ каталога неожиданно отсутствует, Sinkhole использует для него английский текст.
