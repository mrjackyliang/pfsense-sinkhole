Используйте фиксированную команду `/usr/local/sbin/sinkhole` для диагностики и тех же режимов обслуживания, которые вызываются cron и WebGUI.

## Режимы команды \{#command-modes}

| Команда                      | Поведение                                                                                            |
|------------------------------|------------------------------------------------------------------------------------------------------|
| `sinkhole --update`          | Запускает запланированное обновление списков DNS, Bypass и включённых списков IP/стран.              |
| `sinkhole --manual`          | Запускает полное ручное обновление, используемое **Status → Update Now**.                            |
| `sinkhole --apply`           | Применяет сохранённую конфигурацию в фоновом режиме и выполняет только необходимые загрузки.         |
| `sinkhole --refresh-clients` | Перестраивает сетевые подсети и адреса устройств в карте клиентов.                                   |
| `sinkhole --alerts`          | Читает события блокировки и обрабатывает соответствующие правила оповещения.                         |
| `sinkhole --redirect-check`  | Согласует требуемые правила перенаправления обычного DNS и независимо загруженные якоря Bypass и IP. |
| `sinkhole --check-updates`   | Проверяет последний выпуск GitHub и синхронизирует уведомление об обновлении.                        |
| `sinkhole --self-update`     | Загружает, проверяет, анализирует и устанавливает последний выпуск в очереди.                        |
| `sinkhole --help`            | Выводит поддерживаемую строку использования.                                                         |

В автоматизации используйте установленный путь, например `/usr/local/sbin/sinkhole --refresh-clients`. Режимы взаимоисключающие, а обновление списков DNS/Bypass/IP или самообновление, обнаружившее занятую общую блокировку обновления, завершается без запуска конкурирующей операции.

## Постоянные файлы в `/cf/conf/sinkhole` \{#persistent-files}

| Путь                                    | Назначение                                                                                           |
|-----------------------------------------|------------------------------------------------------------------------------------------------------|
| `lists/<id>.domains`                    | Нормализованные последние исправные домены одного списка DNS.                                        |
| `lists/<id>.json`                       | Метаданные обновления этого списка DNS.                                                              |
| `ip-lists/<id>.networks`                | Нормализованные последние исправные сети одного списка IP.                                           |
| `ip-lists/<id>.json`                    | Метаданные обновления этого списка IP.                                                               |
| `bypass-lists/<id>.entries`             | Нормализованные смешанные записи последней исправной копии одного Bypass List.                       |
| `bypass-lists/<id>.json`                | Метаданные обновления этого Bypass List.                                                             |
| `state.json`                            | Постоянное состояние компиляции, развёртывания, предыдущих настроек Resolver, расписания и удаления. |
| `updates.json`                          | Состояние проверки последнего выпуска и устранения дубликатов уведомлений.                           |
| `update-status.json`                    | Ход отдельного самообновления пакета.                                                                |
| `unbound/sinkhole/`                     | Необязательное постоянное зеркало текущего скомпилированного поколения для восстановления RAM-диска. |
| `unbound/sinkhole.d/`                   | Необязательное постоянное зеркало хранилища скомпилированных поколений.                              |
| `unbound/sinkhole-clients/clients.json` | Необязательное постоянное зеркало карты клиентов.                                                    |

Зеркало `unbound/` используется, когда pfSense хранит `/var` на RAM-диске. Sync пакета восстанавливает его в дерево среды выполнения до того, как оно понадобится Resolver.

## Рабочие данные в `/var/db` \{#working-data}

| Путь                                 | Назначение                                                       |
|--------------------------------------|------------------------------------------------------------------|
| `sinkhole-alerts.json`               | Состояние интервала повторения оповещений и часового предела.    |
| `sinkhole-catalog-adguard-home.json` | Кэшированный реестр списков AdGuard Home.                        |
| `sinkhole-catalog-pfblockerng.json`  | Кэшированный каталог источников pfBlockerNG.                     |
| `sinkhole-block-v4.txt`              | Итоговая объединённая таблица блокировки IPv4 после вычитания.   |
| `sinkhole-block-v6.txt`              | Итоговая объединённая таблица блокировки IPv6 после вычитания.   |
| `sinkhole-bypass-v4.txt`             | Итоговая таблица Bypass IPv4 после вычитания защищённых адресов. |
| `sinkhole-bypass-v6.txt`             | Итоговая таблица Bypass IPv6 после вычитания защищённых адресов. |
| `sinkhole-geolite2-country.zip`      | Проверенный архив GeoLite2 Country.                              |
| `sinkhole-geolite2-country.json`     | Метаданные обновления GeoLite2.                                  |

Кэши каталогов и созданные таблицы IP являются воспроизводимыми рабочими данными. Состояние оповещений предотвращает повторную доставку между минутными запусками.

## Временные файлы в `/var/run` \{#transient-files}

| Путь                            | Назначение                                                                      |
|---------------------------------|---------------------------------------------------------------------------------|
| `sinkhole-update.lock`          | Общая блокировка длительных обновлений списков, IP и пакета.                    |
| `sinkhole-runtime.lock`         | Краткая блокировка компиляции, активации и интеграции с Resolver.               |
| `sinkhole-clients.lock`         | Блокировка обновления карты клиентов.                                           |
| `sinkhole-alerts.lock`          | Блокировка обработки оповещений.                                                |
| `sinkhole-redirect-check.lock`  | Блокировка ежеминутной проверки перенаправления.                                |
| `sinkhole-redirect-check.json`  | Первое наблюдение расхождения для проверки перенаправления по двум наблюдениям. |
| `sinkhole-status.json`          | Текущее состояние обновления, компиляции, развёртывания, клиентов и оповещений. |
| `sinkhole-status.json.lock`     | Блокировка координации файла состояния.                                         |
| `sinkhole-ip-anchor.conf`       | Текущие созданные правила для якоря `sinkhole/ip`.                              |
| `sinkhole-ip-anchor.sha256`     | Дайджест для сравнения созданной и загруженной политики IP.                     |
| `sinkhole-ip-status.json`       | Состояние списков IP, GeoLite2, таблиц и якоря.                                 |
| `sinkhole-bypass-anchor.conf`   | Текущие созданные правила для якоря `sinkhole/bypass`.                          |
| `sinkhole-bypass-anchor.sha256` | Дайджест для сравнения созданной и загруженной политики Bypass.                 |

Файлы блокировок координируют задания; само их наличие не доказывает, что их удерживает работающий процесс. Проверьте Status и вывод команды, прежде чем считать блокировку устаревшей.

## Среда выполнения Resolver в `/var/unbound` \{#resolver-runtime}

| Путь                                 | Назначение                                                                    |
|--------------------------------------|-------------------------------------------------------------------------------|
| `sinkhole.py`                        | Проверенный модуль Python, скопированный в корень среды выполнения Unbound.   |
| `sinkhole/`                          | Манифест и данные активного поколения, читаемые модулем.                      |
| `sinkhole.d/`                        | Хранилище скомпилированных поколений, принадлежащее root.                     |
| `sinkhole.d/<generation>/bypass.tsv` | Скомпилированные имена поставщиков, Tor и VPN для ответов DNS Bypass.         |
| `sinkhole-clients/clients.json`      | Текущая карта адресов клиентов в области действия.                            |
| `sinkhole-state/loaded`              | Идентификатор поколения, которое модуль сообщает как загруженное.             |
| `sinkhole-state/events`              | Объединённые события заблокированных ответов, ожидающие обработки оповещений. |
| `sinkhole-state/events.processing`   | Пакет событий, которым сейчас владеет обработчик оповещений.                  |
| `sinkhole-state/events-dropped`      | Число событий, отброшенных после заполнения ограниченной очереди.             |

Эти файлы относятся к среде выполнения, а не к конфигурации. Sinkhole восстанавливает или создаёт их заново через Sync пакета и удаляет при деинсталляции пакета.

Ежеминутное задание карты клиентов и фоновое обновление при Sync выполняются только когда для блокировки DNS включена область сети или устройства либо DNS-защите Bypass требуется определение клиентов. После отключения всех функций Sinkhole следующий Sync удаляет рабочую карту клиентов и её необязательную копию на RAM-диске и не запускает обновление.
