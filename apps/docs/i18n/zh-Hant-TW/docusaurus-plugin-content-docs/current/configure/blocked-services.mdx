如果您想封鎖整個品牌，而不選擇和維護單獨的清單 URL，請使用 **Firewall → Sinkhole → Services**。

## 選擇作用域 \{#choose-a-scope}

選擇 **Global**、一個已設定的網路或一個已設定的設備。搜尋服務，使用群組晶片縮小圖塊範圍，開啟或關閉服務，然後選擇服務卡片下方的 **Save**。

選擇會在該作用域的現有層級編譯。設備允許網域仍優先於設備服務規則，網路允許網域仍優先於網路服務規則，全域允許網域仍優先於全域服務規則。

由專用 Bypass 保護涵蓋的服務不會出現在網格、群組計數或搜尋中。Private Relay 只能在 Bypass 分頁設定。

## 登錄和修復 \{#registry-and-repair}

Sinkhole 僅在此頁面開啟或您選擇 **Refresh** 時取得 AdGuard Home 服務登錄。它會在 `/var/db` 下保留最後一份有效副本一天，因此編譯永遠不會等待網路。

服務標誌會呈現為隔離的 data-URI 圖像。缺少或過大的標誌會使用通用圖像。如果已儲存的服務從較新的登錄中消失，Sinkhole 會保留其 ID 並將其顯示在 **Needs Repair** 下；將其關閉並儲存即可移除該選擇。

**Status** 分頁顯示登錄的取得時間、最後錯誤，以及為每個已設定作用域選擇的已封鎖服務數量。
