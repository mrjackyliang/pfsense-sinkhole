## DNS 基礎 \{#dns-basics}

| 術語               | 別名      | 定義                           |
|------------------|---------|------------------------------|
| **DNS sinkhole** | —       | 使用一個無處可達的地址回應被封鎖的名稱，使請求停止。   |
| **DNS Resolver** | Unbound | pfSense 基於 Unbound 的 DNS 服務。 |

## 清單和作用域 \{#lists-and-scopes}

| 術語             | 別名             | 定義                                           |
|----------------|----------------|----------------------------------------------|
| **封鎖清單**       | —              | 通過 URL 或搜索新增的待封鎖名稱或地址清單。                     |
| **常用清單搜索**     | —              | WebGUI 對廣泛使用的封鎖清單進行的搜索，例如 AdGuard Home 的選擇器。 |
| **已儲存清單**      | —              | 儲存在防火牆上的封鎖清單最後有效副本。                          |
| **作用域**        | —              | 封鎖清單的應用範圍：整個網路、某個 VLAN 或單個設備。                |
| **全局清單**       | —              | 應用於網路中每個用戶端的封鎖清單。                            |
| **SafeSearch** | 安全搜尋、嚴格篩選模式    | 搜尋引擎的安全模式，藉由將該引擎的名稱回應為其安全主機，對作用域內的每台設備強制啟用。  |
| **重新綁定例外**     | private-domain | 儘管有 DNS 重新綁定保護，仍允許以私人地址回應的網域。                |

## 警報 \{#alerts}

| 術語       | 別名  | 定義                         |
|----------|-----|----------------------------|
| **警報規則** | —   | 封鎖事件會發送 pfSense 通知的清單和作用域。 |

## 防止繞過 \{#bypass-protection}

| 術語             | 別名     | 定義                                                                        |
|----------------|--------|---------------------------------------------------------------------------|
| **防止繞過**       | Bypass | 可選的介面級控制，透過重定向普通 DNS 或封鎖常見的加密 DNS 和隧道替代路徑，讓用戶端保持使用 Sinkhole 可以檢查的 DNS 路徑。 |
| **普通 DNS 重定向** | —      | 將設備的普通 TCP 和 UDP 端口 53 查詢傳送到防火牆的可選 Bypass 設定。                             |
